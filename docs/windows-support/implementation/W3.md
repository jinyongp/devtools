## Result and scope

Windows environment overlay is case-insensitive, retains drive environment entries, and rejects ambiguous injected keys without reporting values. The check runs before port preparation, spawn, tool probes, and live replacement preflight. Unix behavior remains separate.

Executable lookup uses the selected PATH/PATHEXT and cwd, supports explicit relative paths with extension lookup, avoids implicit cwd search, and rejects drive-relative names. Windows executable checks use regular-file status rather than Unix execute bits. Batch uses an absolute OS command interpreter, explicit /d /e:on /v:off /s /c and tested quoting. NUL/CR/LF/double-quote/percent batch arguments and percent script paths fail before spawn. .ps1 requires an explicit PowerShell invocation. Direct exe argv, stdio and child exit status are preserved.

The public CLI still has its intermediate unsupported feature gate. W3 does not finish native storage, console signal forwarding, Job ownership, managed process trees, detached daemons or interactive password entry. W3C/W4 implement those separate contracts. Direct child cancellation is tested here; it is not evidence for descendant-tree ownership.
