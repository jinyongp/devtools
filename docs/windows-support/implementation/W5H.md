# W5H — fixed hosts target and CurrentUser certificate trust

Validation authority is native GitHub Actions on both CPUs. Actual PC UAC dialogs, browser behavior and terminal closure remain NOT RUN, as agreed. No local Windows runtime is used.

The one-shot helper uses a local, first-instance, remote-rejecting named pipe with a protected user/SYSTEM DACL. Only a random pipe name appears in argv. Both peers authenticate held process handles, the same user SID, process ID, and the pinned executable's NTFS identity and SHA-256 before exchanging a bounded, strict JSON frame. The image and its parents must deny modification by unrelated users. Client SQOS permits identification, not impersonation. Parent disconnection cancels received work; the existing operation receipt is reconciled on retry.

The private entrypoint accepts only typed hosts, trust and setup requests. Hosts always means the WindowsDirectory API's System32/drivers/etc/hosts. No request chooses a file path or command. Hosts changes use same-user runas only when interactive and not already elevated. Noninteractive hosts changes require an elevated token. CurrentUser trust uses an ordinary same-user child. Isolated mode rejects shared OS changes before helper launch.

Hosts compares the preview digest against the held original and preserves external bytes and existing newline style. A flushed, closed candidate carries the original owner, group, DACL and SACL, verified before one NTFS POSIX replacement through Go Root.Rename. Required metadata privileges are scoped and restored. Sharing conflicts fail without rewriting the original; stale previews, cancellation, missing privileges, reparses and incompatible ACLs fail closed. No in-place rewrite or power-loss guarantee. A helper crash before publication may retain its unique completed temporary file; there is no broad prefix cleanup.

Trust modifies only CurrentUser Root. A private versioned receipt and a random user-defined certificate property jointly establish ownership. Preexisting certificates are never adopted or removed. Prepared/owned/removing states reconcile lost responses without replacing CA keys. A certificate substituted externally fails ownership checks. The helper receives only public certificate material.

Review areas: IPC identity/SQOS/cancellation; fixed target and strict dispatch; hosts digest/atomic publication/security/newlines; certificate ownership and interrupted operations; private CA storage; isolated callers; native TLS, HTTP/2 and WebSocket; Unix compatibility. The final ACL comparison preserves owner/group, every DACL/SACL ACE and mask, inherited ACE flags, NULL/absent ACL state and protection flags. It excludes only `SE_DACL_AUTO_INHERITED` / `SE_SACL_AUTO_INHERITED` control bits: Windows clears them when assigning the candidate descriptor, and their documented child-propagation role does not apply to this regular file. See [descriptor control flags](https://learn.microsoft.com/en-us/windows/win32/secauthz/security-descriptor-control). Independent negative cases reject changed rights, inherited ACE flags, protection, owner/group and audit ACLs. Custom ACL shapes that cannot be preserved fail before publication; there is no repair. The final IPC review found that protocol.Error omits ExitCode from JSON. The private helper response now carries error_exit_code explicitly and restores it in the parent, with a nonzero fallback for malformed operation errors. Native roundtrip checks require ordinary failure exit3 and operation cancellation exit130; context cancellation remains bounded. This prevents an error response from becoming a successful public process exit.

The one-shot private entrypoint also ends its own process on operation-context cancellation. This covers abrupt parent disconnect while an OS confirmation is blocked inside a native API, where cooperative context checks cannot run. Journals/receipts and atomic hosts publication define retry behavior; the product never trusts a disk PID to stop a helper. An isolated native child fixture blocks its operation and must exit130 at the lifetime deadline instead of lingering until the test kills it.
